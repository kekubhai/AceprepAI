# Contributing to AcePrep AI

Thank you for your interest in contributing to AcePrep AI! We welcome contributions from the community.

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/aceprep-ai.git`
3. Install dependencies: `npm install`
4. Create a `.env.local` file with your environment variables
5. Run the development server: `npm run dev`

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes
3. Add tests if applicable
4. Run the linter: `npm run lint`
5. Run the build: `npm run build`
6. Submit a pull request

## Code Style

- Use ESLint and Prettier for code formatting
- Follow the existing code patterns
- Write meaningful commit messages
- Add comments for complex logic

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features.
